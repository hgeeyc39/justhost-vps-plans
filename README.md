## 不限流量，但别把端口速率当成保底

标准 VPS 全系不计量月流量，限制的是端口速率，从 300Mbps 到 1000Mbps。这条路和市面上不少便宜年付产品相反——那些通常是给 2TB、3TB 月流量，超了限速到 10Mbps 或者直接停到下个月。

对流量波动大的用途（图床、文件中转、转发节点、下载），不限流量更省心，不用担心某个月突然跑超。代价是两件事：

端口速率是上限，不是保底。300Mbps 按理论值跑满一天，流量在 3TB 量级，但共享带宽下晚高峰实际速率取决于同宿主邻居，标称 300Mbps 不代表凌晨和晚八点都能跑到 300Mbps。

想要更高峰值只能往上升档。Vega 是 500Mbps，Capella 往上到 750Mbps，Procyon 是 1Gbps。如果用途是单纯的转发或代理，端口速率比核心数重要，1 核 1G 配 300Mbps 往往比 2 核 2G 配 300Mbps 更划算。

## 按用途选，别为用不上的配置付钱

**静态站、Hugo、Typecho 这类轻量博客**：Sirius 就够。20GB NVMe 放一个纯静态站加几十张图绰绰有余，300Mbps 对小站流量来说过剩。没必要上 2G 内存。

**签到脚本、Telegram bot、定时任务**：还是 Sirius，但装 Docker 之后内存会紧张。容器本身加基础镜像常驻就吃掉三四百兆，再跑个 Python 长驻进程容易 OOM。预算允许多花 ¥11/月，Arcturus 的 2G 内存更稳。

**转发节点、代理**：看端口不看核心。Sirius 的 300Mbps 不限流量是这条需求里性价比最高的一档；要更高峰值再考虑 Vega 的 500Mbps。

**一个站 + 数据库 + 管理面板**：Alpha Centauri。2 核 2G 是同时跑 Nginx、MySQL、面板的底线，1G 会在 MySQL 启动后就开始用 swap。

**Docker 多容器、GitLab、Nextcloud**：Capella 起步（4 核 4G / 120G）。GitLab 单独就要 2G 以上内存，Rigel 的 8G 更保险。

**编译、CI、持续高负载**：这个价位不该考虑。全系共享核心，跑满会被同宿主其他虚拟机影响，这不是 JustHost 一家的问题，年付二三十块一月的产品都这样。
